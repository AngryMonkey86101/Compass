# Compass

Оффлайн-навигатор (PWA): стрелка на экране указывает на выбранную точку и показывает расстояние до неё. Работает по GPS и датчикам ориентации телефона.

## Возможности

- выбор, добавление и удаление точек (хранятся в `localStorage`)
- ввод координат: `56.8380, 60.6035`, `56,838; 60,6035`, `56°50′17″N 60°36′13″E` или ссылка из Google Карт, Яндекс Карт, Яндекс Навигатора, `geo:`
- импорт точек из файлов **KML, KMZ, GPX, GeoJSON и CSV**: точки, а также первая вершина линий, полигонов и треков; одноимённые точки при повторном импорте заменяются
- экспорт точек в KML, GPX, CSV и GeoJSON (на телефоне — через «Поделиться» или в «Загрузки»)
- группы до 15 человек: участники видят позиции друг друга (пока приложение открыто), сколько минут назад они обновлялись, и могут выбрать участника целью компаса; всё шифруется на телефоне — см. «Группы» ниже
- сохранение текущего места как точки
- режим «только компас»: двойное нажатие на циферблат скрывает интерфейс, остаются компас, курс и выбранная точка; экран не гаснет (если браузер поддерживает); выход — снова двойное нажатие, «Назад» на Android или Esc
- главное меню (☰): «Навигация», «Мануал» (инструкция), «QR-код приложения» (ссылка на https://claude-compass.netlify.app/), «Поддержать проект» (скоро)
- установка на телефон как PWA, работа без сети
- уведомление о новой версии вместо автоматической перезагрузки

## Перенос точек из Google Карт и Яндекса

- **Одна точка:** долгое нажатие на карте → скопировать координаты (или «Поделиться» → скопировать ссылку) → в Компасе «+» → вставить в поле «Координаты или ссылка». Короткие ссылки `maps.app.goo.gl` и `yandex.ru/maps/-/…` браузер раскрыть не может — для них нужно скопировать координаты.
- **Много точек из Google:** [Google My Maps](https://mymaps.google.com) → создать карту и добавить места → ⋮ → «Экспорт в KML/KMZ» (без флажка сетевой ссылки) → «Импорт» в Компасе. Файл `Saved Places.json` из Google Takeout (или весь архив `.zip`) тоже читается, но Google сохраняет координаты не для всех мест; списки Takeout в CSV содержат только ссылки, координаты в них есть лишь у отмеченных вручную точек.
- **Много точек из Яндекса:** в Навигаторе экспорта избранного нет. Точки можно отметить в [Конструкторе карт Яндекса](https://yandex.ru/map-constructor/) и экспортировать в KML, GPX, CSV или GeoJSON.
- **Таблица:** CSV из Excel или Google Таблиц, например:

  ```
  Название;Широта;Долгота
  Плотинка;56,8380;60,6035
  Ганина Яма;56.9425;60.4718
  ```

  Разделитель `;`, `,` или табуляция; дробная часть — точка или запятая; заголовок по-русски или по-английски (`name`, `lat`, `lon`) в любом порядке столбцов, без заголовка — «название, широта, долгота» или «широта, долгота, название». Кодировка UTF-8 или Windows-1251.
- **Обратно:** «Экспорт» сохраняет точки в KML (Google Earth, My Maps, Конструктор Яндекса), GPX (навигаторы), CSV (Excel, Конструктор Яндекса) или GeoJSON. Любой из этих файлов Компас импортирует обратно без потерь.

## Установка на устройство (без интерфейса браузера)

Компас — PWA: после установки открывается с главного экрана отдельным окном и работает офлайн.

- **iPhone / iPad:** в Safari нажмите «Поделиться» → «На экран „Домой“». Приложение подскажет это само при первом открытии.
- **Android:** кнопка «Установить» в приложении или меню Chrome ⋮ → «Установить приложение».

QR-код со ссылкой на приложение генерирует `npm run qr` (адрес — в `src/config.js`) в `src/assets/app-qr.svg`.

Иконки и заставки iOS генерирует `scripts/generate-pwa-assets.py` (нужен Pillow); он же печатает теги `apple-touch-startup-image` для `index.html`.

## Группы

Работают через свой сервер (`server/`, подробности и настройка VPS — в [server/README.md](server/README.md)). Название группы, ники и координаты шифруются на телефоне ключом группы (AES-GCM, Web Crypto); ключ передаётся только в приглашении — в части ссылки после `#`, которую браузер не отправляет на сервер. Сервер хранит позиции 2 часа, группы без активности удаляет через 7 дней.

- **Адрес сервера** задаётся при сборке: `VITE_GROUPS_API_URL=https://<домен>` — локально в `.env.local` (образец `.env.example`), на Netlify — в переменных окружения сайта (Site configuration → Environment variables), после изменения нужна новая сборка. Пока адрес не задан, раздел «Группы» скрыт.
- **Вступление:** по ссылке или QR-коду; ссылку можно и вставить в «Группы → Вступить по приглашению».
- **Передача позиции** — только пока приложение открыто: при ходьбе раз в 30 с, при стоянии раз в 3 мин, сразу при сдвиге больше 50 м.

## Запуск

```bash
npm install
npm run dev       # разработка
npm run build     # сборка в dist/
npm run preview   # просмотр сборки
npm test          # тесты (vitest)
npm run lint      # oxlint
```

Датчики и геолокация требуют HTTPS (на `localhost` работают и по HTTP). На iOS компас включается кнопкой «Включить компас», так как система запрашивает разрешение.

## Структура

```
src/
  components/   Compass, StatusBar, TargetPanel, CompassDial, LocationList, AddLocationForm,
                CoordsPanel, EventFeed, ImportPanel, ExportPanel, InstallBanner, ErrorBoundary,
                UpdatePrompt; экраны Screen, MainMenu, ManualScreen, QrScreen, SupportScreen,
                GroupsScreen, GroupScreen, JoinScreen, InviteQr
  hooks/        useGeolocation, useDeviceOrientation, useLocations, useEventFeed,
                useInstallPrompt, useFileImport, useRoute (экран из адреса #/…), useWakeLock,
                useGroups, useGroupSync (обмен с сервером групп), useNow
  utils/        geoUtils (расстояние, азимут, разбор координат), angle (сглаживание),
                labels (буквы точек, точность GPS), locationText (координаты и ссылки карт),
                importPoints + csvPoints + pointCollector (импорт файлов), exportPoints,
                saveFile («Поделиться» или скачивание), router (экраны и история),
                doubleTap (двойное нажатие) + тесты
                groupCrypto, groupLogic, groupsApi, groupsStore (группы) + тесты
  assets/       app-qr.svg — QR-код со ссылкой на приложение
  config.js     адрес опубликованного приложения и сервера групп
  data/         locations.json — точки по умолчанию
server/         сервер групп: Node.js без зависимостей, SQLite, Docker, Caddy
```

Версия в интерфейсе берётся из `package.json`.
